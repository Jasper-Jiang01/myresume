# GSAP wind-blown text

A Pen created on CodePen.

Original URL: [https://codepen.io/shubniggurath/pen/jEyZdPj](https://codepen.io/shubniggurath/pen/jEyZdPj).

Using data attributes to drive a procedural GSAP scroll timeline animation, this code allows you to create wind-blown text, either animating in or out, and using a large variety of attributes to get the perfect animation.
